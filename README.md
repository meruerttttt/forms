# forms
полноценную интерактивную анкету (веб-форму) на Django, которая умеет принимать данные от пользователя и проверять их на правильность.
# Django User Form Project

Учебный проект на Django, демонстрирующий создание интерактивной формы с валидацией данных.

Что было сделано:
1. **Форма (`forms.py`)**: 
   - Поле для ввода имени (`CharField`).
   - Поле для указания возраста (`IntegerField`) с ограничением от 1 до 120 лет.
   - Выбор языков программирования (`MultipleChoiceField` с чекбоксами `CheckboxSelectMultiple`).
2. **Обработка и валидация (`views.py`)**: 
   - Реализована серверная проверка введенных данных с помощью метода `form.is_valid()`.
   - Настроена передача обработанных (`cleaned_data`) данных в контекст шаблона.
3. **Интерфейс (`user_form.html`)**: 
   - Создан HTML-шаблон для отображения формы и вывода результатов успешной отправки.
4. **Маршрутизация (`urls.py`)**: 
   - Настроены пути для доступа к форме и работы с задачами в проекте.
